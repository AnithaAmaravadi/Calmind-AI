# 🧮 CalcMind

CalcMind is a modern AI-powered calculator built with HTML, CSS, and JavaScript.

## Features
- Live calculation preview
- Built-in AI assistant
- Calculation history
- Keyboard support
- Dark glassmorphism UI

## Files
- `index.html` - structure
- `style.css` - styling
- `script.js` - logic
